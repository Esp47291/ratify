# ratify

Сайт маркетингового агентства: Яндекс.Директ, SEO-продвижение, аудит сайта и продукта, ведение карточки в Яндекс.Бизнесе. Заявки с форм сохраняются в PostgreSQL и приходят в Telegram.

---

## Запуск через Docker 
Нужны **Docker** и **Docker Compose**. В папке проекта:

```bash
copy .env.example .env
docker compose up -d --build
```
